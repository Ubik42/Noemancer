### GUI、本地化与渲染能力澄清

- Editor 不是“全 RmlUi”或“全声明式”实现：Dock、菜单、Project Hub、Scene View、Animation Graph、Console 与 Agent Context 仍由 Dear ImGui 承载；Edit Inspector 属性区、World Outliner、Asset Browser collection 和项目/游戏 UI 已走 Semantic UI → RmlUi retained/declarative → SDL_GPU。两部分共用领域 Authority，但绘制模型不同。
- 官方启动器现在默认 `zh-CN`，主菜单提供简体中文/English 即时切换；Project Hub、菜单、Command Bar、主面板标题和已有 Semantic Inspector/HUD 词条已有首批中文。ImGui 在 Windows 优先加载微软雅黑简体中文字形范围。当前仍不是完整汉化，也未持久化用户语言偏好；可再分发 CJK 字体仍属于当前前沿。
- 当前真实启用的商业 Raster 路径是 Forward PBR 直接光、split-sum IBL、四级 CSM/局部阴影缓存与 PCF、四 LUT 动态天空大气、Perspective/Orthographic Aerial Perspective、生产 SSR、生产 SSGI、共享 Temporal Denoising、GTAO 加空间双边降噪、Bloom、曝光/调色和 ACES Tone Mapping。Render Graph v17 在 Opaque 后建立完整 RG32F linear view-depth min/max mip chain，SSR 与 SSGI 分别拥有独立 temporal resolve 和 IBL 局部替换 composite；上一帧层级深度还可为静止透视相机下的静态不透明 GPU visibility 提供保守遮挡。共享 Temporal Resolve 再写 color/depth/normal history，并用 motion、depth、normal、reactive、disocclusion 与 neighborhood clamp 限制历史。Hybrid Pixel 仍显式禁用 SSR/SSGI 与 temporal jitter/history。FXAA 只有兼容 Shader/Pipeline/录制分支，默认 Render Graph 未调度，不能标为已启用。RTGI 与 Virtual/Variance Shadow Maps 尚未实现。
- 当前已成立的高性能基础还包括 GPU static opaque 视锥 compact/indexed indirect、稳定 batching/细粒度 dirty upload、共享 HiZ 的保守下一帧遮挡、KTX2 streaming、meshoptimizer Cook、GPU VFX、Render World extraction，以及 D3D12/Vulkan 双后端逐 Render Graph Pass timestamp。Release 固定 1920×1080 的共享屏幕空间基础证据中，D3D12/Vulkan 的 HiZ Seed p95 为 0.0266/0.0226 ms、完整 Reduce p95 为 0.0512/0.0647 ms、Temporal Resolve p95 为 0.0891/0.0932 ms，深度金字塔固定 12 mip/21.095 MiB；证据位于 `generated/acceptance/screen-space-foundation-*-20260825-144925/`。GPU occlusion 已在静止透视相机、静态不透明对象的保守子集合同下成立，并保留 orthographic/skinned/camera-cut/moving/overflow fallback。未成立的是 occupancy/bandwidth、物理 VRAM residency、Native RHI、DXR/Vulkan RT、bindless descriptor、VSM 与 RTGI；`TextureResourceTable` 只证明稳定资源身份和 slot，不能冒充 bindless heap。 阴影扩展证据位于 `generated/acceptance/shadow-scalability-v30-20260825-stress2/`：1,024 个可见 caster、六个本地请求下，两端均选择 3、丢弃 3，Engine policy 返回 `extend-atlas`，Shadow Pass GPU p95 为 0.003072/0.000891 ms；CPU Frame p95 为 42.16/41.57 ms，故总证据按预算失败保留。Virtual Page 目前只有有界领域合同，没有 VSM Shader、页表、物理池或 Render Graph 实现。

- SSR Release 双后端退出证据位于 `generated/acceptance/ssr-v15-20260825-153029/`。D3D12/Vulkan 均在 1920×1080、64 帧捕获、32 帧预热与 60 帧 GPU timestamp 下通过；Reflection ROI 的 mean absolute enabled/disabled delta 为 0.0061395/0.0061396，changed fraction 均为 0.581352，天空控制区 delta 为 0。D3D12 的 HiZ Reduce/Trace/SSR Temporal/Composite p95 为 0.053/0.183/0.061/0.030 ms，Vulkan 为 0.524/0.192/0.499/0.033 ms。画面、confidence debug、法线方向和真实地面反射均以隐藏捕获检查；全程未使用 Computer Use。
