# Noemancer glTF material reference

`material-reference.glb` is a deterministic, redistributable fixture generated by
`scripts/generate-material-reference-asset.ps1`. It contains three material cards
covering OPAQUE, MASK and BLEND together with embedded base-color, tangent-space
normal, metallic-roughness, occlusion and emissive PNG textures.

The geometry, texture patterns and generator are dedicated to the public domain
under CC0-1.0. Regenerate from the repository root with:

```powershell
./scripts/generate-material-reference-asset.ps1
```

The asset intentionally stays small and diagnostic. It validates the ordinary
Asset Registry -> fastgltf -> renderer path; it is not a second material system
or a claim that synthetic cards replace production art.
